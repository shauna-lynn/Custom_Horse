### Tools & Resources
I highly recommend [DexyFex's CodeX](https://www.patreon.com/dexyfex/join) for exploring and editing game files. Download links are in their Discord server once you get Patreon roles. At the time of writing, v30 is the most recent version but I've had more luck with v29 for most things I work with. I have uploaded my [Codex.Games.RDR2.strings](Codex.Games.RDR2.strings.txt). It is very rough, doesn't look pretty, however it gets the job done and will expose a LOT of different hash strings.
