## IDs, indices and expressions

- **Bone ID / tag** is the decimal `<Tag>` value stored with the bone name.
- **Source index** is the zero-based `<Index>` within that particular skeleton. The head has its own index space, starting at zero; do not concatenate these indices or use them as fixed runtime entity indices.
- **Parent** is resolved through that source skeleton's `<ParentIndex>`. The facial root has no local parent, but its skeleton's `ParentBoneTag` is `51051` (`SCALE_Head`) in the base skeleton.
- **Expression ID** is a deformation input, not a bone ID. The horse YED exports use the element name `BoneId` for expression-channel references too; the surrounding track and instruction determine its meaning. See [Expressions](YMT%20Method.md#expressions).

For scripting, resolve a bone by name on the actual entity with `GetEntityBoneIndexByName`; check for a missing result before using the returned runtime index. Bone-ID and bone-index native parameters are not interchangeable.
